A make.fun bounty entry for **Funniest Autocorrect Fail** — a funny autocorrect fail, in one line.

`main.py` (Python 3, standard library only) writes the entry text to `/output/entry.txt` and validates it first: exactly one line, 1–199 characters.

Run it with:
